## 2024-11-20 - String Scanning vs Array Allocation with RegEx
**Learning:** In hot paths like continuous user input processing, string scanning using simple backward loops is significantly faster (around ~25x in local benchmarks) compared to splitting a string into an array using a regular expression (`.split(/[+\-*/]/)`). Array allocations and regex engine overhead introduce unnecessary performance penalties that can be entirely avoided.
**Action:** When validating specific conditions at the end of a string (like checking for an existing decimal in the current number segment), prefer backward looping and character checking over splitting strings and checking array segments, particularly in environments without JS bundlers/optimizers where native string operations excel.
